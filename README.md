# Urban Oasis - Condotel Booking Platform Concept

**Urban Oasis** is a UX/UI concept design project representing a bespoke, single-building short-term rental platform (a "Condotel"). 

## The Concept Context

While standard platforms like Airbnb solve the broad short-term rental problem, the **hyper-local, single-building premium rental experience** is a massive emerging market. When you book a standard Airbnb, you just get a room. When you build a bespoke platform for a *single* luxury building, you offer an integrated experience. 

This project explores the UX required to elevate a stay from a standard rental to a 5-star hotel experience. Guests aren't just booking a room; they are booking access to the building's exclusive spa, private chef, rooftop lounge, and 24/7 concierge.

### Key Narrative Elements

*   **The Booking UX:** The Hero section features a seamless booking bar (Check-in, Check-out, Guests) integrated directly into a cinematic view of the building. 
*   **Available Suites:** We replaced standard real estate listings with a booking feed. Suites show nightly rates, and the UI focuses on date selection and guest capacity rather than purchase price.
*   **Guest Services (Amenities):** The amenities section is framed around "Guest Privileges," highlighting the exclusive access short-term renters get to the building's 5-star facilities (Infinity Pool, Spa, Sky Lounge).
*   **The Narrative:** The history section tells the story of architect Elias Sterling's vision—a sanctuary that opens its doors to discerning travelers looking for an intimate, resident-hosted retreat rather than a transient hotel.

## Technology Stack

*   **Frontend Framework:** React (Vite)
*   **Styling:** Tailwind CSS (Dark Mode aesthetic with Glassmorphism)
*   **Icons:** Lucide React

2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
